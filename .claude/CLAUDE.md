# Git Workflow

После завершения каждой поставленной задачи:

1. Проверь состояние репозитория:
   git status

2. Добавляй в commit только файлы, относящиеся к текущей задаче.

3. Не добавляй:
   - .env
   - secrets
   - passwords
   - API keys
   - bin/
   - obj/
   - .vs/

4. После завершения задачи создай commit:
   git add <нужные файлы>
   git commit -m "<понятное описание изменений>"

5. После успешного commit выполни:
   git push origin main

6. После push проверь, что он завершился успешно.

7. Если push завершился ошибкой, сообщи об ошибке и не скрывай её.

8. Никогда не используй без моего разрешения:
   git push --force
   git reset --hard

9. Работай в ветке main.

10. В конце сообщи:
   - что изменено;
   - commit hash;
   - успешно ли выполнен push.
